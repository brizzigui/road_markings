# Modelo para classificação da conservação de marcações rodoviárias

Este repositório contém os datasets, código de treino e modelo treinado apresentados no trabalho "Sinalização vista de cima: desenvolvimento de um modelo de visão computacional para classificação da conservação de marcações rodoviárias", apresentado na I ERAMIA-RS.
Leia o artigo em: [Sinalização vista de cima: desenvolvimento de um modelo de visão computacional para classificação da conservação de marcações rodoviárias](https://sol.sbc.org.br/index.php/eramiars/article/view/39429/39201).


## Composição

- A pasta `dataset` contém o dataset principal.
- A pasta `test` contém o dataset adicional de teste.
- A pasta `model` contém o código de treinamento do modelo.
- O modelo treinado está na pasta raiz, sendo o arquivo .keras
